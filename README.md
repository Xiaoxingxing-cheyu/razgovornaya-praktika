# Chinese Learning Robot V1.0

Локальная веб-платформа для начальной разговорной практики китайского языка. Интерфейс показывает русский текст над китайским переводом. / 面向中文初学者的本地口语练习网页。界面中俄双语显示，俄语在上、中文在下。

## Запуск / 运行

Требуется Node.js 18 или новее. В Windows можно запустить `start.bat`: он откроет страницу и оставит окно сервера открытым. / 需要 Node.js 18 或更新版本。在 Windows 上可双击 `start.bat` 启动；它会打开课程页面并保留服务器窗口。

```bash
npm start
```

Если команда `npm` не установлена, запустите встроенный сервер напрямую: `node server.js`. Для базовой проверки модулей выполните `node --test`. / 如果环境没有 `npm` 命令，可直接运行：`node server.js`。运行基础模块测试：`node --test`。

Откройте <http://127.0.0.1:4173>. Ссылка на урок: `http://127.0.0.1:4173/?lesson=lesson1`. Чтобы остановить сервер, нажмите `Ctrl+C` в терминале. / 打开 <http://127.0.0.1:4173>。课程链接示例：`http://127.0.0.1:4173/?lesson=lesson1`。在运行服务器的终端按 `Ctrl+C` 停止。

## Курсы / 课程

Скопируйте `config/lesson1.json` в новый файл, например `config/lesson2.json`, задайте уникальный `lesson_id` и добавьте вопросы. Каждому вопросу нужны `question_ru`, `question_zh`, `correct_answers`, три элемента `hints`, `wrong_message` и `success_message`. Допустимые варианты ответа перечисляются явно: автоматической проверки смысла нет. Чтобы открыть новый урок, используйте `?lesson=lesson2`. / 将 `config/lesson1.json` 复制为新文件（例如 `config/lesson2.json`），设置唯一的 `lesson_id` 并添加题目。每道题需要俄语和中文题目、`correct_answers`、三级 `hints`、错误反馈和正确反馈。可接受答案必须明确配置；系统不做语义判断。用 `?lesson=lesson2` 打开新课程。

## Персонаж / 人物

Измените `config/avatar.json`: поле `image` указывает путь к изображению. Файл можно заменить в `assets/avatars/`; если он не загрузится, появится встроенная заглушка. Для нового персонажа измените `name_ru`, `name_zh` и тексты приветствия. / 修改 `config/avatar.json` 中的 `image` 路径即可替换人物图片，素材放在 `assets/avatars/`。图片加载失败时会显示内置占位人物。也可修改人物名称和欢迎语。

## Речь и данные / 语音与数据

Нажмите кнопку микрофона и разрешите доступ. Распознавание использует Web Speech API на языке `zh-CN`; поддержка зависит от браузера, а распознавание может обращаться к онлайн-службе поставщика браузера. Синтез речи использует китайский голос, доступный в системе. Если распознавание недоступно или запрещено, отправьте ответ через текстовое поле. / 点击麦克风并允许访问。语音识别使用 `zh-CN` Web Speech API，兼容性因浏览器而异，识别过程可能使用浏览器厂商的在线服务。语音播放使用系统提供的中文语音。不支持识别或拒绝麦克风权限时，可用文字输入回答。

Записи сохраняются только в LocalStorage текущего браузера. Преподаватель не получает их автоматически. Кнопки экспорта создают JSON или UTF-8 CSV с BOM для совместимости с Excel; экспортируются вопросы, отмеченные для преподавателя. / 学习记录仅保存在当前浏览器的 LocalStorage，教师不会自动收到记录。导出按钮生成 JSON 或带 BOM 的 UTF-8 CSV（便于 Excel 打开），内容为待教师答疑题目。

## Проверка речи вручную / 手动测试语音

Откройте урок в актуальном Chrome или Edge через `localhost`, разрешите микрофон, произнесите ответ по-китайски и проверьте распознанный текст. Для проверки отказа микрофона запретите разрешение сайту в настройках браузера и нажмите микрофон. Для проверки отсутствия Web Speech API используйте браузер, который его не реализует; поле ввода остаётся доступным. / 使用较新的 Chrome 或 Edge 通过 localhost 打开课程并允许麦克风，用中文回答以检查识别结果。测试权限拒绝时，在浏览器站点设置中禁用麦克风后再点击按钮。可在不支持 Web Speech API 的浏览器中检查兼容提示；文字输入始终可用。

## Ограничения и дальнейшая работа / 当前限制与后续方向

Это фиксированные упражнения с точным сравнением настроенных ответов. Речь зависит от браузера и может требовать интернет-соединения; свои серверы распознавания и синтеза не используются. Данные не синхронизируются между устройствами. В дальнейшем можно добавить редактор уроков, больше курсов и персонажей, сводку экспортов для преподавателя и доступность с клавиатуры. / 当前版本使用固定题目和配置答案精确匹配。语音能力依赖浏览器，且可能需要联网；项目没有自建语音服务器。记录不会跨设备同步。后续可增加课程编辑器、更多课程与人物、教师导出汇总及键盘无障碍优化。
